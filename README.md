# しろたび

白い犬が旅をして、付喪神と旅の写真風カードを連れ帰る放置系コレクションゲームです。

## ファイル構成

- `index.html`: ゲーム本体
- `manifest.json`: PWA設定
- `sw.js`: オフライン起動用 Service Worker
- `icon-192.png`: ホーム画面用アイコン
- `icon-512.png`: ホーム画面用アイコン
- `icon.svg`: PNG未使用時の仮SVGアイコン

## GitHub Pages での公開手順

1. GitHubで新しいリポジトリを作成
2. このフォルダ内のPWA関連ファイルをアップロード
3. Settings → Pages → Branch: main → Save
4. `https://ユーザー名.github.io/リポジトリ名/` でアクセス可能

## スマホへの追加手順

### iPhoneの場合

1. Safariでゲームのページを開く
2. 下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 「追加」をタップ

### Androidの場合

1. Chromeでゲームのページを開く
2. 右上のメニュー（⋮）をタップ
3. 「ホーム画面に追加」をタップ
